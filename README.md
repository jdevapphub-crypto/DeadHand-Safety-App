What's in This Release
DEAD HAND V5.2 is a Progressive Web App (PWA) providing three safety modes for personal and group protection.

Safety Mode (Premium)
Check-in timer from 1 minute to 24 hours

Live GPS location captured and included in every alert

Automatic SMS and Email alerts to 2 emergency contacts if the timer expires

Live map view of your own last known position while armed

Group Safety Mode (Free)
2 to 4 phones connected over WiFi or mobile data

Live shared map showing every member's position in real time

Automatic alert when any member drifts beyond the configurable distance threshold (default: 100 m)

Vibration, banner, and popup with a live map link when an alert triggers

Random 5-character group codes (DH-XXXXX) for quick joining

Will Mode (Premium)
Delivers a final message to up to 7 recipients

Duration from 1 minute to 7 years

SMS and Email delivery per recipient

Live GPS location appended to every delivery
